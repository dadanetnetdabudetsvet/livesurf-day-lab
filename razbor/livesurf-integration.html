Что меняется по спеке (docs/livesurf-day-bonus.md)

  1. Один тип вместо трёх. Бэкенд отдаёт один элемент стека — everyday-bonus (или новый daily-hub), в data которого есть и приветствие (user_login, first_visit), и бонус (breakdown), и `level_up: {level, credits, skill, pro_days, vip_days} | null. Типы everyday-welcome и level-up` в стек не кладутся, когда есть daily-hub.
  2. Claim в окне. Нужна ручка POST /api/bonus/everyday/claim с телом { day_id, idempotency_key } и ответом `{ credits, experience, level, op_id, level_up }. Кнопка «Забрать» перестаёт быть ссылкой на /bonus`. Машина состояний — preview/ls-day-logic.js (claimReduce).
  3. Данные для блоков по сценариям. В data добавляются: projects_yesterday: [{id, name, visits, paused}], paused_projects, days_since_visit, experience_decay: {amount, date} | null, program_today: {credits, skill, shows} | null, deeds: [...]. Правило выбора сценария — pickScenario(facts); его можно считать на бэкенде и передавать scenario в data.
  4. Полоса опыта уже есть в шапке: после claim обновить shell.experience_current и user.level из ответа, чтобы полоса сдвинулась без перезагрузки; точка «бонус ждёт» гаснет по подтверждению (блок K8).
  5. Апселлы остаются kind: upsale со своими правилами, но не показываются следом за ежедневным окном в той же сессии (maxPopupsPerSession: 1).

Как переносить

  • Разметка блока — projects/livesurf/blocks/catalog.html ([data-id]), стили — blocks.css + popup-skin.css + tokens.css. В репозитории токены объявляются на классе окна (как .ls-landing у лендингов), а не на :root, чтобы не утечь в кабинет.
  • Поведения — preview/ls-blocks-live.js: каждая функция — один блок, без зависимостей; в Vue переносятся как методы компонента.
  • Логика — preview/ls-day-logic.js: чистые функции, покрываются тестами по образцу shared/**/__tests__.
  • Тексты — через i18n (shared/locales/ru.json, ключи modal.everydayBonus.* расширяются), захардкоженных строк не оставлять.
  • Кегль не мельче 12px, кнопки от 44px, бирюза для текста на белом — затемнённая #0E7C8E (планка docs/livesurf/13-design-standard.md).
