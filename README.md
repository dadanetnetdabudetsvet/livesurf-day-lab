# Лаборатория ежедневного окна LiveSurf

Страница: каталог из 131 блока ежедневного окна, живой прототип и конструктор
сборки с расчётом эмиссии. Собрана по независимому аудиту геймификации.
Все данные на странице демонстрационные.

- `index.html` — лаборатория одним файлом
- `katalog.html` — каталог блоков с живыми примерами
- `okna/` — двенадцать собранных окон по сценариям
- `razbor/` — текстовый разбор версии 2 и заметки об интеграции

Собирается скриптами из мастерской попап-окон, руками не правится.
